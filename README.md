# Python Calculator

## About the Project
This is a simple calculator built with Python. It allows users to perform basic mathematical operations through a text-based menu.

The program also keeps a history of previous calculations while it is running.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus (remainder)
- Exponentiation
- View calculation history
- Handle invalid number inputs
- Prevent division and modulus by zero
- Exit the program

## Technologies Used
- Python
- Loops and conditional statements
- User input and output
- Lists
- Exception handling

```text
calculator/

```

## How to Run
1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in your code editor.
4. Run the following command in the terminal:

```bash
python calculator1.py
```

## How to Use
1. Run the program.
2. Choose an operation from the menu.
3. Enter the first and second numbers.
4. View the calculation result.
5. Choose the history option to view previous calculations.
6. Choose the exit option to close the program.
